# VitaCoach AI

AI-powered fitness assistant built with LangChain and Streamlit.

## Features

- BMI calculator
- Daily calorie calculator
- Exercise recommendations
- User profile memory
- Streamlit chat interface

## Technologies

- Python
- LangChain
- OpenAI GPT-4o-mini
- Streamlit

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
